About Me

Projects

Voron Trident Build

The Voron Trident is a fully DIY 3D Printer, built entirely from readily available hardware store parts. Mine was actually built using a secret technique known as "buying a for-parts machine instead of a kit and just replacing the broken stuff". This technique allowed me to build the printer for much cheaper while also allowing me to replace any low-quality parts with brand-name equivalents.

This website

This very website is also one of my projects. I did spent a great deal of time making it, after all, so why should it not count as one? Built using the good-old strategy of reading documentation and avoiding flexboxes like the plague.

And besides, recursion is one of the free software community's longest running jokes.

Recoil

Recoil is actually the oldest project on this list. It's a tabletop roleplaying game which I have spent the better part of half a decade working on. Each system and subsystem is built to interact with the rest of the game, allowing for build variety never seen before in a tactical shooter TTRPG.

The Recoil Character Sheet

A WIP project intended to replace the current spreadsheet-style character sheeet for recoil. It's also meant to function as my bachelor's project.

Neonlaces

These shoelaces are a project that was dead ever since I started designing them. Who would've thunk that using fragile LED strings on by far the most demanding place on the whole body is going to be a bad idea?

The Jacket

Recoil may be my longest running project, but its importance to my life pales in comparison to the might of the "Cyberjacket" (horrible name). It's what has landed me my current job, as well as what has allowed me to become a part of the communities that I now call family.
